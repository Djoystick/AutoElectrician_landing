## [1.2.0] - 2026-09-18

### 🔒 Critical Security & Stability Fixes (Backend API Audit)

#### api/index.js — критические исправления:
- **[SEC] Rate Limit** `POST /api/requests`: подключён `limiterPublic` (30 req/min) — закрыта уязвимость DoS/спам-заявок.
- **[SEC] Telegram HTML-инъекция**: добавлена функция `escapeTgHtml()`, применена в уведомлениях бота — спецсимволы `<>&` больше не ломают parse_mode HTML.
- **[BUG] `createdAt` маппинг в заявках**: `GET /api/requests` и `PUT /api/requests/:id/status` теперь возвращают `createdAt: r.created_at` — даты заявок корректно отображаются в admin.js.
- **[BUG] `.single()` → `.maybeSingle()`**: исправлено в 4 местах (`PUT /api/reviews/:id`, `POST /api/masters`, `POST /api/clients/:id/repairs`, `DELETE /api/clients/:id/repairs/:rid`) — устранены аварийные падения с PGRST116 при отсутствии записи.
- **[BUG] Вход мастера через Telegram**: в `/api/client/me` добавлена проверка `telegram_chat_id` при определении мастерских прав — кнопка «Панель Мастера» теперь появляется при входе через Telegram.
- **[BUG] Смена пароля мастера** (`PUT /api/settings`): пароль теперь bcrypt-хешируется и сохраняется в таблице `masters` (не в `settings`); возвращается новый JWT токен — не теряется доступ к админке.
- **[BUG] Ложный разлогин клиентов**: `clientAuth` теперь отличает ошибки БД (`503`) от истёкших сессий (`401`) — не разлогинивает клиентов при временной недоступности Supabase.
- **[NEW] `GET /api/services`** (authCheck): защищённый эндпойнт возвращает все услуги, включая неактивные — деактивированные услуги больше не исчезают из панели администратора.
- **[BUG] Аналитика выручки**: `Number(r.cost)` вместо `typeof === 'number'` — строки-числа (`"500"`) теперь корректно суммируются.
- **[BUG] Churn-анализ**: последний ремонт определяется сортировкой по дате, а не позицией в массиве.

#### public/js/admin.js:
- **[BUG] Смена пароля**: устранена критическая ошибка — токен больше не заменяется на plain-text пароль; используется новый JWT из ответа сервера.
- **[BUG] Услуги**: `loadAndShow()` теперь загружает услуги через защищённый `GET /api/services` (все, включая неактивные).

#### public/js/profile.js:
- **[BUG] Ложный разлогин**: при ответе 503 (ошибка БД) токен клиента больше не очищается из localStorage.
