# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-09-10

### 🛡️ Security & Architecture (Аудит Astra / OpenRouter Nemotron 120B Super)
- **Унификация бэкенда**: `server.js` преобразован в модульный раннер поверх `api/index.js`, устранено дублирование эндпоинтов и расхождение контрактов между локальной средой и Vercel.
- **Устранение утечки секретов (SEC-01)**: удалены открытый мастер-пароль `admin`, токен Telegram бота и личный Chat ID из `data/data.json`. Добавлен `.env.example` с шаблоном переменных окружения.
- **Изоляция CRM и публичного API (SEC-02)**: реализован строгий DTO-фильтр `publicLandingDto` в `GET /api/data`. Клиентская база и заявки больше никогда не отдаются неавторизованным пользователям.
- **Защита Telegram Webhook (SEC-03)**: добавлена проверка заголовка `X-Telegram-Bot-Api-Secret-Token` с использованием `crypto.timingSafeEqual` против timing attacks.
- **Устранение privilege escalation в профиле (SEC-04, SEC-05)**: метод `GET /api/client/me` больше не выдает JWT администратора; `GET /api/client/profile` больше не возвращает мастер-пароль.
- **XSS-санитизация (SEC-07)**: в `admin.js` и `profile.js` обновлена функция `esc()` для экранирования апострофов и обратных кавычек, добавлена функция `sanitizePhone()` для безопасных ссылок `tel:`.
- **Защита эндпоинтов и маршрутизация (SEC-08)**: удален открытый эндпоинт `/api/debug`, закрыт логгер `/api/logs` с `authCheck`, исправлен конфликт маршрутов `PUT /api/reviews/reorder` и `PUT /api/reviews/:id`. Добавлены недостающие маршруты управления автомобилями клиента (`POST /api/clients/:id/cars`, `DELETE /api/clients/:id/cars/:cid`). Сохранены поля напоминаний о ТО (`reminderDate`, `reminderText`).

### 🎨 UI/UX & Living Motion (OpenRouter UI/UX Agent)
- **Живой статус мастера**: внедрен неоновый статус-индикатор мастера с круговой радарной пульсацией CSS (`@keyframes pulseRadar`) в Hero-блоке, адаптирующийся к статусу приема заявок и поддержкой `prefers-reduced-motion`.
- **Экспресс-калькулятор неисправностей**: разработан интерактивный 3-шаговый калькулятор поломок (категория авто, симптом, ориентировочная стоимость и время прибытия) с прямой интеграцией в модальное окно заявки.
- **Маскот «Электрон» по запросу**: отключен навязчивый принудительный онбординг при загрузке страницы. Маскот переведен в режим деликатного помощника-диагноста по клику с быстрыми чипами неисправностей.
- **Разделение формы и маскота**: отправка формы заявки (`/api/requests`) вынесена в `main.js`, гарантируя 100% работоспособность оформления вызова независимо от декоративного маскота.
- **Очистка репозитория**: удалены устаревшие файлы миграций, дампы логов и тяжелые тестовые изображения.
